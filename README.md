# MomoTalk
  MomoTalk Web —— 网页版《蔚蓝档案》桃信（MomoTalk）二创工具

一款纯网页、免安装的 MomoTalk 风格聊天制作工具，用来复刻/续写你和学生们
的「桃信」对话，并导出成长图分享。


一、MomoTalk Web 是什么
----------------------------------------------------------------
打开浏览器即可使用的《蔚蓝档案》(Blue Archive) MomoTalk（桃信）模拟器。
不用安装客户端、不用登录账号，所有数据都保存在你自己的浏览器本地，
可以用来做剧情二创、同人对话、整活梗图。

二、功能一览
----------------------------------------------------------------
【学生库与联系人】
  · 内置学生库，支持搜索、按学校筛选，一键把学生加入「我的学生」；
  · 支持学生皮肤/形态切换，同一个学生可以创建多个聊天（重复添加）；
  · 联系人列表按最近修改时间排序，显示创建时间与修改时间。

【聊天页 · 信息盒子】
  · 同一发送者的多条消息自动聚合为一个「信息盒子」，头像与名字只显示一次；
  · 老师（老师 / Sensei）消息右对齐、无头像无名字；学生消息左对齐带头像；
  · 发送 = 新建信息盒子；追加 = 把消息并入上一个信息盒子；
  · 身份不一致时会询问处理方式，不会弄乱你的聊天记录；
  · 长按信息盒子进入编辑面板：追加消息、删除单条、上移/下移、更换发送者、
    删除整个盒子、拆分盒子、相邻盒子合并。

【输入框「＋」更多栏（6 个入口）】
  · 社团表情：内置 183 张游戏表情，点击即发送，尺寸与图片消息一致；
  · 本地图片：选图后自动压缩保存，无需上传服务器；
  · 回复框：浅蓝面板，标题固定、可添加多个选项（最多 6 个），
              选项逐个显示，播放时可点击选择；
  · 好感故事：按游戏原版重绘的粉色卡片（心形水印 + 粉色标题条 + 粉色按钮）；
  · 旁白1：居中的淡灰色小字，用于叙述性文字；
  · 旁白2：居中的灰底黑字圆角块，用于时间/地点提示。

【播放模式】
  · 按顺序逐字显示聊天气泡，带「正在输入」动画；
  · 回复框会停下来等待你点击选项，选择后继续播放；
  · 旁白、好感故事等卡片直接出现（无打字动画），节奏更像游戏本体；
  · 播放过程中真实数据不会被改动。

【聊天截图】
  · 一键把整段对话生成为长图（Canvas 绘制，2 倍清晰度）；
  · 截图版式与网页内保持一致（气泡、表情、图片、回复框、好感故事、旁白）；
  · 头像/图片跨域加载失败时会自动走代理回退，尽量不出现空白占位；
  · 生成后可预览、保存图片。

【数据安全】
  · 数据和设置全部存在浏览器 localStorage，不上传任何服务器；
  · 支持导出 / 导入 JSON（含版本号与旧数据迁移，聊天 ID 自动去重）；
  · 自动备份，可手动备份与恢复；
  · 「清除本地数据」一键重置（红色按钮，二次确认）。

【其它】
  · 通用设置：界面文案、角色名、水印等均可自定义；
  · 所有界面文案集中在 resources/running_datas.json，可直接改成自己喜欢的说法；
  · 手机竖屏优先设计，电脑浏览器同样可用。


三、特点
----------------------------------------------------------------
1. 免安装、免账号：静态网页，双击或起个静态服务器就能用。
2. 隐私友好：数据只在本地，不联网、不上传。
3. 还原度高：气泡、字号、配色、表情尺寸、播放节奏都对齐游戏本体。
4. 内容可自定义：文案、学生库、表情、配置全部是外部 JSON/图片，替换即可。
5. 导出好看：长图截图与网页所见一致，适合直接分享到社交平台。
6. 轻量无依赖：不使用框架与构建工具，改完刷新即生效。

  test-harness.html            自动化测试页面

    video.json                 教程视频配置
    *.jpg / *.png              图标与占位图

  _test/shots/                 界面预览图


五、快速开始
----------------------------------------------------------------
方式一：直接双击 index.html（部分浏览器限制本地 fetch 时请看方式二）。
方式二（推荐）：在项目目录启动任意静态服务器，然后浏览器访问。

  · Node.js：  node _test/serve.js . 8765      → http://127.0.0.1:8765
  · Python：   python -m http.server 8765     → http://127.0.0.1:8765

注意：必须通过 HTTP 访问，直接 file:// 打开时配置文件可能加载失败。


六、进阶：把界面改成你自己的
----------------------------------------------------------------
  · 改文案：编辑 resources/running_datas.json 里的 texts 字段；
  · 改联系方式/赞赏码：改 running_datas.json 里的 contact / donate；
  · 换学生库：替换 resources/students.json；
  · 换表情：把图片放进 resources/emoji/ 并更新配置；
  · 改配色：编辑 resources/momotalk.css。
改动后刷新浏览器即可生效，无需构建。


七、常见问题
----------------------------------------------------------------
Q：打开是白屏/提示配置加载失败？
A：请用静态服务器访问（见「快速开始」），并确认
   resources/running_datas.json 存在且可访问。

Q：换电脑/清缓存后聊天记录没了？
A：数据存在浏览器本地，请先「导出数据」保存 JSON，换设备后再导入。

Q：截图里头像或图片是空白？
A：远程图片没有跨域头时，会先直连、再自动经由图片代理（默认
   https://images.weserv.nl/）加载；如仍空白，可在 running_datas.json 的
   screenshot.imageProxy 换成其它带 Access-Control-Allow-Origin 的代理。

Q：手机上能用吗？
A：可以，界面按手机竖屏设计，电脑浏览器也能正常使用。
