# MomoTalk

网页版《蔚蓝档案》(Blue Archive) Momotalk（桃信），@zako老师 开发，只是一只小小的初中生呀，有建议可发送邮件至 zakosensei@icloud.com，感谢大家的支持！

## 功能

- 学生库浏览、添加学生形态、导入/导出聊天数据（JSON）
- 聊天页「信息盒子」：
  - 同一发送者的多条消息聚合为一个信息盒子，头像与名字只显示一次；
  - 老师（Sensei）发送的消息不显示头像与名字，右对齐蓝色气泡；
  - 信息盒子里每个气泡的首条带指向头像一侧的小尖角（学生左侧 / 老师右侧），同一盒子后续气泡不带尖角；
  - 发送 = 新建信息盒子；追加 = 把消息加入上一个信息盒子；身份不一致时会询问处理方式；
  - 长按信息盒子进入编辑面板：追加信息、删除消息、上移/下移（调换顺序）、更换发送者、删除整个信息盒子。
- 输入框右侧「＋」更多栏：
  - 社团表情（`resources/emoji/` 下 183 张表情）；
  - 本地图片（自动压缩后保存）；
  - 回复框（浅蓝面板，**标题固定为「回复」不可修改**，可编辑/添加多个回复选项；面板居中显示；点击某个选项后该选项作为消息输出，播放模式中必须选择一个回复才能继续）；
  - 好感故事框（粉色面板，居中对齐；**标题固定为「好感故事」、按钮文案固定为「进入{学生名}的好感故事」且不可编辑**；**仅老师可发送**）；
  - 表情差分（**仅学生可发送**；图片来自 `resources/students.json` 里该学生的 `gallery` 立绘/表情差分图集）；
  - 回复框/好感故事框可长按信息盒子删除；回复框长按可修改选项（好感故事不可编辑）。
- 聊天页右上角：
  - 播放：逐条回放聊天内的每一条信息，学生每条消息前有「三点轮流变小」的打字动画（每次只播放一次动画周期），时长可在「更多 → 学生设置 → 打字动画时间」调整（700ms～2000ms，默认 1000ms；支持滑杆与键盘输入两种方式）；播放遇到回复框时会暂停，必须选择一个回复作为消息输出后才能继续；
  - 截图：把聊天内容（不含顶栏、输入框、导航栏）绘制成一张长图，支持预览与保存 PNG。
- 更多 → 学生设置：
  - 添加自定义学生：可自定义头像（本地图片）、学生姓名，并自动分配唯一编号（900001 起）；自定义学生会同步出现在学生选择器与会话列表，可删除；
  - 打字动画时间支持键盘输入。
- 更多 → 通用设置：默认视频网站、自动备份（默认关闭；开启后每次退出聊天页自动下载 JSON 备份）。
- 页面细节：打开「更多」子栏目隐藏底部导航、联系人列表下拉刷新、右滑返回、页面/消息进入动画。

## 本地运行

项目通过 `fetch` 读取 `resources/*.json`，不能直接双击 `index.html` 打开，需要静态 HTTP 服务：

```powershell
# 在 MomoTalk 目录下执行
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/index.html
```

## 数据说明

- 聊天数据保存在浏览器 localStorage：
  - `momotalk_chats_v8`：信息盒子结构（`{ studentId: [box, ...] }`）；
  - `momotalk_my_students_v7`：已添加的学生；
  - `momotalk_custom_students_v1`：学生设置里添加的自定义学生（编号 / 姓名 / 头像 dataURL）；
  - `momotalk_settings_v1`：通用设置（含动画时间、自动备份开关）。
- 旧版 `momotalk_chats_v7` 的扁平消息数据会在启动时自动迁移到新结构，旧数据不会被删除。
- 导入兼容旧版（version ≤ 3，扁平 chats）与新版（version 4，盒子 chats）导出文件；重复导入会按盒子内容签名去重。
