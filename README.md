# MomoTalk
  MomoTalk Web —— 网页版《蔚蓝档案》桃信（MomoTalk）二创工具
=

一款纯网页、免安装的 MomoTalk 风格聊天制作工具，用来复刻/续写你和学生们
的「桃信」对话，并导出成长图分享。


一、MomoTalk Web 是什么
----------------------------------------------------------------
打开浏览器即可使用的《蔚蓝档案》(Blue Archive) MomoTalk（桃信）模拟器。
不用安装客户端、不用登录账号，所有数据都保存在你自己的浏览器本地，
可以用来做剧情二创、同人对话、整活梗图。

二、功能一览
----------------------------------------------------------------
【学生库与联系人】
  · 内置学生库，支持搜索、按学校筛选，一键把学生加入「我的学生」；
  · 支持学生皮肤/形态切换，同一个学生可以创建多个聊天（重复添加）；
  · 联系人列表按最近修改时间排序，显示创建时间与修改时间。

【聊天列表 · 备注 / 标签 / 分组 / 排序】
  · 备注：给每个聊天写一句备注（不超过 30 字），显示在聊天条名字下方；
  · 标签：一个聊天最多 8 个标签，显示在聊天条右侧（超出用「+n」收起）；
  · 分组：可新建 / 重命名 / 删除分组，列表按分组分段显示，未归组的聊天
    自动落到「未分组」段；
  · 排序：拖动聊天条右侧的「⋮⋮」手柄即可拖动排序（同分组内排序），也可以
    置顶聊天，置顶的聊天永远排在最前面；
  · 搜索：主页顶部搜索框支持按 姓名 / 标签 / 备注 / 分组名 筛选（搜索时列表
    变回单列，方便一眼看到命中项）；
  · 长按聊天条（或右键）打开「管理会话」，可一次改完备注、标签、分组、模式、
    置顶与未读数量；列表右上角「分组」按钮进入分组管理。

【聊天页 · 信息盒子】
  · 同一发送者的多条消息自动聚合为一个「信息盒子」，头像与名字只显示一次；
  · 老师（老师 / Sensei）消息右对齐、**无头像无名字**；学生消息左对齐带头像；
  · 居中的「回复框 / 好感故事框 / 旁白」按游戏原版参考图重绘：回复框为浅青灰面板
    + 灰蓝竖条标题 + 标题分隔线 + 白底灰边选项；好感故事为浅粉卡片 + 粉色竖条标题
    + 标题分隔线 + 粉色按钮；旁白1 为近黑居中文字、旁白2 为灰绿药丸；
  · 发送 = 新建信息盒子；追加 = 把消息并入上一个信息盒子；
  · 「追加」只对普通消息生效：**回复框、好感故事框、旁白之后不允许追加信息**
    （按钮会置灰并提示，请改用「发送」新建一条），避免把卡片挤进同一个盒子；
  · 身份不一致时会询问处理方式，不会弄乱你的聊天记录；
  · 长按信息盒子进入编辑面板：追加消息、删除单条、上移/下移、更换发送者、
    删除整个盒子、拆分盒子、相邻盒子合并。

【输入框「＋」更多栏（6 个入口）】
  · 社团表情：内置 183 张游戏表情，点击即发送，尺寸与图片消息一致；
  · 本地图片：选图后自动压缩保存，无需上传服务器；
  · 回复框：浅蓝面板，标题固定、可添加多个选项（最多 6 个），
              选项逐个显示，播放时可点击选择；
  · 好感故事：按游戏原版重绘的粉色卡片（心形水印 + 粉色标题条 + 粉色按钮）；
  · 旁白1：居中的淡灰色小字，用于叙述性文字；
  · 旁白2：居中的灰底黑字圆角块，用于时间/地点提示。

【播放模式】
  · 按顺序逐字显示聊天气泡，带「正在输入」动画；
  · 回复框会停下来等待你点击选项，选择后继续播放；
  · 旁白、好感故事等卡片直接出现（无打字动画），节奏更像游戏本体；
  · 播放时发送栏会自动隐藏，播放结束恢复；
  · 播放过程中真实数据不会被改动。

【分享单个聊天 · 编辑模式 / 播放模式】
  · 聊天页右上角（播放按钮左侧）新增「导出」按钮，可单独导出一个聊天文件；
  · 导出前会询问「分享方式」并填写聊天备注，文件里包含：分享方式（编辑 / 播放
    模式）、导出时间与应用版本、聊天备注、完整聊天内容；
  · 编辑模式：收到的人可以继续编辑这段聊天；
  · 播放模式：打开聊天后立刻自动播放，播放进度自动保存（关掉再打开会接着播），
    播放完成后回复框不会复原成选项、不显示播放进度、不允许修改聊天内容；
  · 单聊文件用主页右上角的「导入」直接导入，会作为一个新聊天出现在列表里。

【自定义学生 · 表情差分】
  · 在「更多 → 学生设置 → 添加自定义学生」里可以选择本机的表情差分文件夹；
  · 目录与编号约定：`学生姓名/001.jpg … xxx.jpg`（三位编号，支持 jpg/png/webp）；
  · **编号必须从 001 开始**（起始编号最小为 1，000.jpg 之类的文件会被忽略）；
  · 选择文件夹后会自动识别编号范围，并需要确认「编号范围（0-n 中的 1-n）」；
    只有范围内的图片会保存，编号有缺失会提示；
  · 差分图片本地压缩保存；预览格子按正方形自适应显示**完整图片**（不再裁切），
    发送时在「表情差分」面板里按学生选择即可。

【自定义学生 · 导入 / 导出（.zip）】
  · 「学生设置」里可以导出单个自定义学生（或一键导出全部）为 .zip，表情差分
    一并打包（`学生姓名/001.jpg …`）；
  · 导入 .zip 会自动恢复学生信息、头像与表情差分；同名学生再导入会更新而不是
    重复添加；
  · zip 内同时写入 `student.json`（或 `students.json`）清单，方便手工检查。

【聊天截图】
  · 一键把整段对话生成为长图（Canvas 绘制，2 倍清晰度）；
  · 截图版式与网页内保持一致（气泡、表情、图片、回复框、好感故事、旁白）；
  · 头像/图片跨域加载失败时会自动走代理回退，尽量不出现空白占位；
  · 生成后可预览、保存图片。

【数据安全】
  · 数据和设置全部存在浏览器 localStorage，不上传任何服务器；
  · 支持导出 / 导入 JSON（含版本号与旧数据迁移，聊天 ID 自动去重；分组与播放
    进度一起备份）；
  · 支持导出 / 导入单个聊天（JSON）与自定义学生（.zip，含表情差分）；
  · 自动备份，可手动备份与恢复；
  · 「清除本地数据」一键重置（红色按钮，二次确认）。

【其它】
  · 手机竖屏优先设计，电脑浏览器同样可用。
  · 当前版本：Version 0.1.0。


三、特点
----------------------------------------------------------------
1. 免安装、免账号：静态网页，双击或起个静态服务器就能用。
2. 隐私友好：数据只在本地，不联网、不上传。
3. 还原度高：气泡、字号、配色、表情尺寸、播放节奏都对齐游戏本体。
4. 内容可自定义：文案、学生库、表情、配置全部是外部 JSON/图片，替换即可。
5. 导出好看：长图截图与网页所见一致，适合直接分享到社交平台。
6. 轻量无依赖：不使用框架与构建工具，改完刷新即生效。


四、文件格式说明（导出 / 导入）
----------------------------------------------------------------
【单聊文件 momotalk_chat_<学生名>_<时间>.json】
  在聊天页点「导出」生成，可再通过主页「导入」还原成一个新聊天。
  {
    "type": "momotalk-chat",
    "version": 1,
    "appVersion": "Version 0.1.0",   // 应用版本
    "exportedAt": "2026-11-22T06:10:00.000Z",  // 导出时间
    "mode": "edit" | "play",         // 分享方式：编辑模式 / 播放模式
    "note": "聊天备注（≤30 字）",
    "student": { "id": 100, "name": "小鸟游 星野", "avatar": "…" },
    "customStudent": { … } | null,   // 自定义学生时附带其定义（含差分）
    "chat": { "id": "…", "tags": ["主线"], "boxes": [ …信息盒子… ] }
  }

【学生包 momotalk_student_<学生名>_<时间>.zip / momotalk_students_<时间>.zip】
  在「更多 → 学生设置」里导出，可整包迁移自定义学生（含表情差分）：
    student.json        单个学生的清单（多个学生时为 students.json）
    <学生姓名>/avatar.jpg
    <学生姓名>/001.jpg  // 表情差分按三位编号，001 … xxx
    <学生姓名>/002.jpg …
  student.json 结构：{ name, avatarPath, diffRange: { start, end },
                       diffs: [ { n: 1, path: "<学生姓名>/001.jpg" }, … ] }

【完整备份 momotalk_backup_<时间>.json / momotalk_autobackup_<时间>.json】
  version 6：myStudents（含备注 / 标签 / 分组 / 置顶 / 顺序 / 模式）、chats、
  customStudents（含差分）、groups（分组）、progress（播放进度）。


五、常见问题
----------------------------------------------------------------
Q：换电脑/清缓存后聊天记录没了？
A：数据存在浏览器本地，请先「导出数据」保存 JSON，换设备后再导入。

Q：截图里头像或图片是空白？
A：远程图片没有跨域头时，会先直连、再自动经由图片代理（默认
   https://images.weserv.nl/）加载；如仍空白，可在 running_datas.json 的
   screenshot.imageProxy 换成其它带 Access-Control-Allow-Origin 的代理。

Q：手机上能用吗？
A：可以，界面按手机竖屏设计，电脑浏览器也能正常使用。
